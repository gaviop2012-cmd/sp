Local execution and network transparency

SpotDL Studio runs the download engine on this Mac. It does not send Spotify URLs or media through a developer-operated proxy or download server. The app makes direct outbound requests from this device to GitHub for release checks, to Spotify-related endpoints for metadata, and to supported media providers for matching audio. Those services may receive your IP address and request information under their own policies.

Updates install official stable SpotDL and yt-dlp package releases into the app-managed Python environment. This is compatibility maintenance, not a mechanism for bypassing DRM, access controls, or a service's restrictions.
